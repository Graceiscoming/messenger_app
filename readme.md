# CP353 Project 

## Technology ที่กำหนดให้ใช้
Presentation Layer : ใช้อะไรทำก็ได้
Domain Layer : ใช้ ASP.Net (REST API)
Data Access Layer : ใช้ Entity Framework (EF)
Database : ใช้ PostgresQL

## การใช้ AI
อนุญาตให้ใช้ AI ช่วยได้ แต่เราต้องคุม Design ให้เป็นตามต้องการได้
และต้องเข้าใจว่าโค้ดส่วนใดทำอะไร เผื่อต้องแก้ไขเอง (เนื่องจาก AI ก็รวนได้ (AI Halucination))
ให้แจ้งด้วยว่าใช้ AI ที่ส่วนใดบ้าง และผลเป็นอย่างไร
